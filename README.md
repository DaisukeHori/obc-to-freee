# obc_to_freee — 勘定奉行 → freee 仕訳インポート変換ツール

[![GitHub Pages](https://img.shields.io/badge/web%20app-online-brightgreen)](https://daisukehori.github.io/obc-to-freee/)
[![Python](https://img.shields.io/badge/python-3.8%2B-blue)](https://www.python.org/)
[![License](https://img.shields.io/badge/license-MIT-lightgrey)](#ライセンス)

勘定奉行 (OBC) のエクスポート CSV を、**freee 会計の「他社会計ソフト仕訳のインポート」用 CSV** に変換するツールです。取引先マスタも同時生成でき、同名重複エラーを対話的に解消できます。

---

## 1. このツールでできること

| 機能 | 説明 |
|------|------|
| 📄 仕訳変換 | 奉行エクスポート CSV を freee 33 列拡張テンプレート (UTF-8 BOM) CSV に変換 |
| 🌍 エンコーディング自動判定 | CP932 / UTF-8 / UTF-8 BOM / UTF-16 を自動認識 |
| 🔀 カラム順序非依存 | カラム名で値を取得するため、奉行の列順が変わっても動作 |
| 👥 取引先補填 | 借方・貸方の取引先コードと取引先名を freee の専用列へ転記 |
| 🔄 複合仕訳分解 | 奉行の「1 行に両側データあり」を freee の「借方明細行 + 貸方明細行」に自動分解 |
| 🏦 普通預金 → 口座名 | 「普通預金 + 補助科目」を freee の口座名仕訳へ自動置換 |
| 💯 税区分マッピング | 課仕入 / 課売上 / 共仕入 / 課仕免 / 共仕免 / 課売返 / 非売上 / 非仕入 + 税率 (10% / 8% 軽減) を freee 公式コードに変換 |
| 🧹 改行除去 | 摘要や取引先名の余計な改行を半角スペースに自動置換 |
| 📅 期間カット | 任意期間のみ切り出し可能 |
| 📂 自動分割 | 行数しきい値でファイル分割。**伝票境界をまたがず**安全に分割 |
| 🔍 監査ログ | 奉行原本の借貸不一致伝票・課売上マイナス疑い仕訳を一覧表示 |
| 📒 取引先マスタ CSV 生成 | 奉行原本から取引先コード+名のユニークリストを抽出、freee 取引先インポート用 57 列テンプレート準拠 CSV を出力 |
| 🤝 同名重複対処 | 同一名に複数コードがある場合、対話的または自動で統合 / 別名化 / スキップを選択 (7 戦略) |
| 🧮 整合性検算 | 6 層検算 (列数 / 税区分 / 金額 / 列数 / 日付 / 借貸合計) |

## 2. Web 版の使い方 (推奨)

### ステップ 1 ブラウザで開く

URL をクリックしてください: **https://daisukehori.github.io/obc-to-freee/**

### ステップ 2 奉行 CSV をドラッグ&ドロップ

画面上部の大きなエリアに、奉行からエクスポートした CSV ファイル (`奉行_勘定奉行仕分伝票データ上.csv` など) をドラッグ&ドロップ。複数ファイル同時に投入可能。

### ステップ 3 オプションを設定

- **出力ファイル名プレフィックス**: 出力 CSV の名前の先頭
- **1 ファイル最大行数**: 大きすぎる場合は分割 (推奨 10,000)
- **期間カット**: 一部期間だけ変換したい場合に開始日・終了日を指定
- **取引先マスタも生成** にチェック (推奨)
  - **同名重複対処**: `自動: 最頻使用コードに統合 (推奨)` でほとんどのケースを解決

### ステップ 4 「変換実行」をクリック

ブラウザの中で全部変換が走り、数秒〜十数秒で結果が表示されます。

### ステップ 5 結果を確認・ダウンロード

- **サマリカード**: 行数・取引先件数・監査ログ件数
- **出力 CSV 一覧**: 各ファイルをダウンロード
- **CSV テーブルプレビュー**: ソート・検索可能
- **監査ログ**: 経理担当の手動確認が推奨される伝票一覧
- **freee アップロード手順**: 次に何をすべきかが画面で案内されます

設定はブラウザに保存され、次回開いた時に復元されます (localStorage)。実行履歴も自動保存。

## 5. Python CLI 版

自動化・バッチ処理・サーバー連携に最適。

### 基本コマンド (Mac/Linux)

```
python3 obc_to_freee.py \
  --input "奉行_勘定奉行仕分伝票データ上.csv" "奉行_勘定奉行仕分伝票データ下.csv" \
  --output-dir "./output" \
  --output-prefix "freee用_仕訳データ_obc変換" \
  --rows-per-file 10000 \
  --output-partners \
  --dedup-strategy=merge-most-used
```

### 基本コマンド (Windows)

```
python obc_to_freee.py --input 奉行_勘定奉行仕分伝票データ上.csv 奉行_勘定奉行仕分伝票データ下.csv --output-dir output --output-prefix freee用_仕訳データ_obc変換 --rows-per-file 10000 --output-partners --dedup-strategy=merge-most-used
```

### CLI 引数一覧

| 引数 | 必須 | 既定値 | 説明 |
|------|------|--------|------|
| `--input` | ✅ | — | 奉行 CSV ファイル (複数指定可) |
| `--output-dir` | ✅ | — | 出力先ディレクトリ |
| `--output-prefix` | — | `freee用_仕訳データ_obc変換` | 仕訳 CSV 名のプレフィックス |
| `--rows-per-file` | — | `10000` | 1 ファイルあたりの最大データ行数 |
| `--from` | — | なし | 開始日 `YYYY/MM/DD` (両端含む) |
| `--to` | — | なし | 終了日 `YYYY/MM/DD` (両端含む) |
| `--encoding` | — | `auto` | 奉行 CSV のエンコーディング (`auto` / `cp932` / `utf-8` / `utf-8-sig`) |
| `--quiet-audit` | — | `False (抑制しない)` | 監査ログを抑制 |
| `--output-partners` | — | `False (出力しない)` | 取引先マスタ CSV を追加出力 |
| `--partners-prefix` | — | `freee取引先マスタ` | 取引先マスタファイル名のプレフィックス |
| `--dedup-strategy` | — | `warn-only` | 同名異コード対処戦略 (`warn-only` / `interactive` / `merge-most-used` / `merge-lowest` / `merge-highest` / `suffix` / `custom`) |
| `--dedup-custom-json` | — | — | `custom` 戦略時の選択を JSON ファイルで指定 |
| `--detect-duplicates-only` | — | — | 同名異コード検出結果のみ JSON で stdout 出力して終了 |

### 期間カット例

```
python3 obc_to_freee.py [基本引数] --from 2025/11/01 --to 2026/02/28
```

## 6. freee へアップロードする手順

### ステップ A: 取引先マスタを先に取り込む (必須・推奨)

1. freee 会計にログイン
2. **マスタ・口座 → 取引先** を開く
3. 右上 **[…] → CSV インポート** をクリック
4. **「取引先コードを元にインポート」** を選択 ← 重要
5. `freee取引先マスタ.csv` をドラッグ&ドロップ
6. プレビュー確認 → **「インポートの実行」**

### ステップ B: 仕訳 CSV を取り込む

1. **取引入力 → 振替伝票** を開く
2. 右上 **インポート → 他社会計ソフト仕訳のインポート** をクリック
3. `freee用_仕訳データ_obc変換_001.csv` をアップロード
4. **税額の扱い** を選択 (税抜経理 → 「外税」、税込経理 → 「内税 + 自動計算」)
5. 「設定する」
6. マッピング画面で勘定科目・補助科目・税区分を確認
7. **「インポートを実行」**
8. `_002.csv`, `_003.csv` … と順に同じ手順を繰り返す

### ⚠️ 過去マッピングの削除 (重要)

過去にインポートしたマッピング設定が残っていると、「借方取引先コード」のプルダウンがグレーアウトすることがあります。その場合:

「**4 新規データの設定**」内の **「科目のインポート設定」** リンク → **「すべて削除」** → 再アップロード

### ロールバック

「**仕訳インポート履歴**」 → 該当行の **「削除」** ボタン (取り込んだ振替伝票が一括削除)

## 7. 入力ファイルの柔軟性

### 対応するエンコーディング (文字コード)

- **CP932 (Shift-JIS)** — 奉行の標準出力
- **UTF-8** / **UTF-8 BOM** / **UTF-16** (BOM 必須)

すべて自動判定します。手動指定したい場合は `--encoding cp932` 等。

### カラム順序の変更

奉行のバージョン違いや手動編集で列順が変わっていても動作します。**カラム名で値を取得**するため。

### 必須カラム

| カラム名 | 用途 |
|---------|------|
| `日付` | freee の日付列 |
| `伝票No.` | freee の伝票番号 + 同一伝票のグルーピング |
| `借方勘定科目名` | freee の借方勘定科目 |
| `借方本体金額` | freee の借方金額 |
| `貸方勘定科目名` | freee の貸方勘定科目 |
| `貸方本体金額` | freee の貸方金額 |

これらがないとエラー停止して、欠落カラム名 + ネクストアクションを表示します。

### オプショナルカラム (無くても処理継続)

取引先・部門・補助科目・税区分・税率・摘要・消費税額 など。該当 freee 列が空欄になるだけ。

## 8. 同名重複の対処

**freee は取引先マスタで同名の重複行を許容しません**。奉行原本で同一名に複数コードがあると、何らかの対処が必要です。

### 7 つの対処戦略

| 戦略 | 動作 | 用途 |
|------|------|------|
| `warn-only` | 警告のみ。何もしない (デフォルト) | 警告だけ確認したい |
| `merge-most-used` | **使用回数最多のコードに自動統合** (推奨) | 大半のケース |
| `merge-lowest` | 最小コードに自動統合 | 古いコードを残したい |
| `merge-highest` | 最大コードに自動統合 | 新しいコードを残したい |
| `suffix` | `_2`, `_3` で自動別名化 | 別取引先として残したい |
| `interactive` | CLI で標準入力プロンプト、1 件ずつ選択 | 細かく制御 |
| `custom` | GUI で 1 件ずつカード選択 (Web 版・Python GUI 版で利用) | 視覚的に判断 |

統合 (`merge-*`) を選ぶと、**仕訳 CSV のコード列も自動的に書き換え**られるため、freee インポート時のマッチング成功が保証されます。

### 例

```
$ python3 obc_to_freee.py [基本引数] --output-partners --dedup-strategy=merge-most-used

[同名異コード対処結果] dedup-strategy=merge-most-used
処理した同名異コード: 3 件

  エクシードシステム㈱:
    元: コード 742001 / 746209
    選択: コード 742001 に統合 (merge-most-used)
    結果: 仕訳の 746209 → 742001 に置換 (1 件の仕訳が影響)
  ...
```

## 10. 困ったとき

詳細は [FAQ.md](FAQ.md) を参照。よくある質問の抜粋:

### freee で「マスタで未登録の取引先があります」と全件確認画面が出る

→ `--output-partners` で取引先マスタを生成し、**先に取引先マスタを取り込んで**から仕訳をインポートしてください。

### freee で「名前(通称)の重複でインポートできません」と出る

→ `--dedup-strategy=merge-most-used` を付けて再変換してください。同名重複が自動統合されます。

### 「借方取引先コード」のプルダウンがグレーアウト

→ freee の「科目のインポート設定」から過去マッピングを **すべて削除**してから再アップロードしてください。

### `python: コマンドが見つかりません`

→ [12. Python のインストール](#12-python-のインストール) を参照。または Web 版を使えば Python 不要。

### 文字化けして見えます

→ スクリプトは CP932 / UTF-8 / UTF-8 BOM / UTF-16 を自動判定するため通常は問題ありません。出力 CSV を Excel で開く際、Excel 2016 以降なら UTF-8 BOM を正しく扱います。

```
借方金額, 借方税区分, 借方税額,
貸方勘定科目, 貸方科目コード, 貸方補助科目, 貸方取引先, 貸方取引先コード,
貸方部門, 貸方品目, 貸方メモタグ, 貸方セグメント1〜3,
貸方金額, 貸方税区分, 貸方税額,
摘要
```

UTF-8 with BOM (`EF BB BF`)、全データ行は `[明細行]` で開始、各行の借方金額 = 貸方金額 (freee 振替伝票仕様準拠)。

### 11-2. 取引先マスタフォーマット (freee 57 列テンプレート)

`名前（通称）` `取引先コード` `正式名称（帳票出力時に使用される名称）` の 3 項目を埋め、残り 54 列は空欄。

### 11-3. 行分解ルール

| 奉行行 | freee 出力 |
|--------|-----------|
| 借方のみ | 1 行: 借方 = 奉行借方 / 貸方 = 「複合」(同額・対象外) |
| 貸方のみ | 1 行: 借方 = 「複合」(同額・対象外) / 貸方 = 奉行貸方 |
| 両側あり | 2 行: 借方明細行 + 貸方明細行 (摘要は両行へ複製) |
| 両側空 | スキップ (奉行の空パディング行) |

### 11-4. 税区分マッピング

| 奉行略称 | + 税率 | → freee コード |
|----------|-------|----------------|
| 課仕入 | 10 | 課対仕入10% |
| 課仕入 | 8 | 課対仕入8%（軽） |
| 課売上 | 10 | 課税売上10% |
| 課売上 | 8 | 課税売上8%（軽） |
| 共仕入 | 10 | 共対仕入10% |
| 共仕入 | 8 | 共対仕入8%（軽） |
| 課仕免 | 10 | 課対仕入（控80）10% |
| 課仕免 | 8 | 課対仕入（控80）8%（軽） |
| 共仕免 | 10 | 共対仕入（控80）10% |
| 共仕免 | 8 | 共対仕入（控80）8%（軽） |
| 課売返 | 10 | 課税売返10% |
| 課売返 | 8 | 課税売返8%（軽） |
| 非売上 | — | 非課売上 |
| 非仕入 | — | 非課仕入 |
| 空 / 対象外 | — | 対象外 |

> 注: 税率 `0` または空欄の場合は `対象外` として処理。想定外の組み合わせは「対象外」で仮置きしてエラーレポートに一覧表示。

> ⚠️ **保守時の注意 (開発者向け)**: 税区分マッピング (`TAX_MAP`) は **Python 版 `obc_to_freee.py` が正本**ですが、JavaScript 単独版 `obc_to_freee.html` (および GitHub Pages 上の `index.html`) にも独立した `TAX_MAP` 定数が存在します。`FREEE_HEADER` / `FREEE_PARTNER_HEADER` / `REQUIRED_COLS` / `OPTIONAL_COLS` も同様です。これらを変更する際は **両方を同期更新**してください。同期漏れがあると Python 版と JS 版で異なる出力結果になります。

### 11-5. ノイズ除去

- 取引先名 = `その他取引先` または空白のみ → 空欄
- 取引先コード = `000000` または空白のみ → 空欄
- 部門名・補助科目 = `その他` → 空欄
- セル内 `\r`/`\n`/`\r\n` → 半角スペース 1 個
- 連続スペース → 1 個に縮約

### 11-6. ファイル分割

`--rows-per-file 10000` 指定時、伝票境界優先で分割。同一 (日付, 伝票番号) が複数ファイルに分かれることなし。

### 11-7. freee 仕様の制約 (公式 PDF より)

- 1 ファイル最大 50,000 行 / 64 MB
- 必須列: `[表題行]`, 日付, 借方勘定科目, 借方税区分, 借方金額, 貸方勘定科目, 貸方税区分, 貸方金額
- 同一ファイル内で (日付, 伝票番号) の重複は同一伝票扱い

## 12. Python のインストール

> Web 版だけ使うなら Python 不要です。GUI/CLI 版を使いたい場合のみ参照。

確認:
```
python3 --version
```

`Python 3.8.x` 以上であれば OK。

### Windows

1. 公式: https://www.python.org/downloads/windows/
2. **Add python.exe to PATH** にチェックを入れて Install
3. コマンドプロンプトを新しく開き直して `python --version`

### Mac (Homebrew 推奨)

```
brew install python@3.12
python3 --version
```

または公式: https://www.python.org/downloads/macos/

### Linux (Ubuntu/Debian)

```
sudo apt update
sudo apt install -y python3 python3-pip
python3 --version
```

(Fedora/CentOS/RHEL は `sudo dnf install python3`)
