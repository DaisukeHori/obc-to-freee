# obc_to_freee.py — 勘定奉行 → freee 仕訳インポート変換

## 1. このスクリプトでできること

| 機能 | 説明 |
|------|------|
| 一気通貫変換 | 奉行エクスポート CSV を freee 33 列拡張テンプレート UTF-8 BOM CSV に変換 (CP932 / UTF-8 / UTF-8 BOM / UTF-16 自動判定、カラム順序非依存) |
| 取引先補填 | 奉行の借方・貸方の取引先コードと取引先名を freee の専用列へ転記 |
| 複合仕訳分解 | 奉行の「1 行に両側データあり」を freee の「借方明細行 + 貸方明細行」に自動分解 (借貸 100% 一致) |
| 普通預金 → 口座名 | 「普通預金 + 補助科目」を freee の口座名仕訳へ自動置換 |
| 税区分変換 | 奉行の `課仕入`/`課売上`/`共仕入`/`課仕免`/`共仕免`/`課売返`/`非売上`/`非仕入` + 税率を freee コードに変換 |
| 改行除去 | 摘要や取引先名の余計な改行を半角スペースに自動置換 |
| 期間カット | `--from` / `--to` で任意期間を切り出し |
| 自動分割 | 行数しきい値でファイル分割。**伝票境界をまたがず**安全に分割 |
| 監査ログ | 奉行原本の借貸不一致伝票・課売上マイナス疑い仕訳を実行時に一覧表示 |
| 取引先マスタ CSV 生成 | `--output-partners` で奉行原本から取引先コード+名のユニークリストを抽出し、freee 取引先インポート用 57 列テンプレート準拠 CSV を出力 |

## 2. 準備:Python のインストール

スクリプトを動かすには **Python 3.8 以上** が必要です。すでにインストール済みの方は [3. 作業フォルダを決める](#3-準備作業フォルダを決める) へ進んでください。

確認コマンド (ターミナル/コマンドプロンプトを開いて以下を実行):

```
python3 --version
```

`Python 3.8.x` などと表示されれば OK。`コマンドが見つかりません` のエラーが出た場合は以下の手順でインストール。

---

1. 公式サイトを開く: https://www.python.org/downloads/windows/
2. 「Latest Python 3 Release」のリンクをクリック
3. ページ下部の「Files」セクションから **Windows installer (64-bit)** をダウンロード
4. ダウンロードした `.exe` をダブルクリック
5. インストーラーが開いたら、**画面下部の「Add python.exe to PATH」に必ずチェック**を入れる ← 重要
6. 「Install Now」をクリック
7. 「Setup was successful」と出たらインストール完了、ウィンドウを閉じる
8. **コマンドプロンプトを新しく開き直して** (古いウィンドウでは PATH が反映されていません)、以下を実行:

```
python --version
```

`Python 3.x.x` と表示されれば成功。

> 💡 **コマンドプロンプトの開き方 (Windows)**
> スタートメニューの検索ボックスに `cmd` と入力 → 「コマンドプロンプト」をクリック。

## 3. 準備:作業フォルダを決める

スクリプトは **どこのフォルダに置いても動きます**。決まった場所にしばられません。例えば次のどこでも OK:

- Windows: `C:\Users\あなたの名前\Documents\freee変換\`
- Mac: `/Users/あなたの名前/Documents/freee変換/`
- Linux: `/home/あなたの名前/freee変換/`
- USB メモリの中、デスクトップ、ダウンロードフォルダ、共有ドライブ … どこでも可

この説明では、**作業フォルダ** という呼び方で統一します。以下、作業フォルダを `freee変換` という名前で作る前提で進めます (名前は何でも構いません)。

---

## 4. 使い方:基本の 4 ステップ

### ステップ 1 ファイルを所定の場所に置く

作業フォルダの中に、以下のファイルを置きます:

```
freee変換/
├ obc_to_freee.py                              ← 本スクリプト
├ 奉行_勘定奉行仕分伝票データ上.csv             ← 奉行からエクスポートした上半期分
└ 奉行_勘定奉行仕分伝票データ下.csv             ← 奉行からエクスポートした下半期分
```

奉行 CSV のファイル名は何でも構いません。後でコマンドに直接書きます。

---

### ステップ 2 ターミナルを開いてフォルダへ移動

#### Windows の場合

1. エクスプローラーで作業フォルダ (`freee変換`) を開く
2. アドレスバーをクリックしてアドレスを全選択 → そこに `cmd` と入力して Enter
3. そのフォルダ位置でコマンドプロンプトが開く

または手動で:

```
cd "C:\Users\あなたの名前\Documents\freee変換"
```

(パスは実際の場所に置き換え。引用符で囲む)

#### Mac の場合

1. ターミナル.app を開く
2. 以下のコマンドを実行 (パスは実際の場所に置き換え):

```
cd "/Users/あなたの名前/Documents/freee変換"
```

または:Finder で作業フォルダを開いた状態で、フォルダのアイコンをターミナルウィンドウへ **ドラッグ&ドロップ**するとパスが自動入力されます。

#### Linux の場合

ターミナルを開いて:

```
cd "/home/あなたの名前/freee変換"
```

---

### ステップ 3 変換コマンドを実行

作業フォルダに移動した状態で、以下のコマンドをそのままコピペして実行します。

#### Windows の場合

```
python obc_to_freee.py --input 奉行_勘定奉行仕分伝票データ上.csv 奉行_勘定奉行仕分伝票データ下.csv --output-dir output --output-prefix freee用_仕訳データ_obc変換 --rows-per-file 10000
```

#### Mac / Linux の場合

```
python3 obc_to_freee.py --input 奉行_勘定奉行仕分伝票データ上.csv 奉行_勘定奉行仕分伝票データ下.csv --output-dir output --output-prefix freee用_仕訳データ_obc変換 --rows-per-file 10000
```

> 💡 Windows は `python`、Mac/Linux は `python3` です。

#### 引数の意味

| 引数 | 意味 |
|------|------|
| `--input ファイル名1 ファイル名2` | 奉行 CSV ファイル (複数指定可) |
| `--output-dir output` | 出力先フォルダ名 (なければ自動作成) |
| `--output-prefix 名前` | 出力ファイルの名前の先頭 |
| `--rows-per-file 10000` | 1 ファイルあたりの最大行数 |
| `--encoding auto` | 奉行 CSV のエンコーディング (省略可。`auto` / `cp932` / `utf-8` / `utf-8-sig`)。デフォルトは `auto` で自動判定 |

> 💡 **奉行 CSV の保存形式について**
> 奉行から出力される CSV は通常 Shift-JIS (CP932) ですが、別ツールで UTF-8 や UTF-8 BOM 付きに変換したものでも自動判定して読み込めます。**カラム (列) の順番が変わっていても動きます**。カラム名で判定するため、`日付` や `伝票No.` などの名前さえ正しければ列順序は気にしなくて構いません。

---

### ステップ 4 出力 CSV を確認

実行後、作業フォルダの中に `output` フォルダが自動でできて、変換済 CSV が入っています。

```
freee変換/
├ obc_to_freee.py
├ 奉行_勘定奉行仕分伝票データ上.csv
├ 奉行_勘定奉行仕分伝票データ下.csv
└ output/
   ├ freee用_仕訳データ_obc変換_001.csv         ← freee にアップロードするファイル (1 つ目)
   └ freee用_仕訳データ_obc変換_002.csv         ← freee にアップロードするファイル (2 つ目)
```

このファイルをそのまま freee の「他社会計ソフト仕訳のインポート」へドラッグ&ドロップすれば取り込めます ([6. freee へアップロードする手順](#6-freee-へアップロードする手順) 参照)。

## 5. 期間を絞り込んで実行する

「2 月末までだけインポートしたい」「11 月分だけ」のように期間を絞れます。

#### Windows の場合

```
python obc_to_freee.py --input 奉行_勘定奉行仕分伝票データ上.csv 奉行_勘定奉行仕分伝票データ下.csv --output-dir output --output-prefix freee用_仕訳データ_obc変換_2月末まで --rows-per-file 10000 --from 2025/11/30 --to 2026/02/28
```

#### Mac / Linux の場合

```
python3 obc_to_freee.py --input 奉行_勘定奉行仕分伝票データ上.csv 奉行_勘定奉行仕分伝票データ下.csv --output-dir output --output-prefix freee用_仕訳データ_obc変換_2月末まで --rows-per-file 10000 --from 2025/11/30 --to 2026/02/28
```

- `--from YYYY/MM/DD` 開始日 (両端含む)
- `--to YYYY/MM/DD` 終了日 (両端含む)
- 日付は `2025/11/30` のように **半角スラッシュ** 区切り

省略すると全期間を出力します。

## 6. freee へアップロードする手順

1. freee 会計にログイン
2. 上部メニューの **取引入力 → 振替伝票** をクリック
3. 振替伝票画面の右上、**インポート ボタン → 他社会計ソフト仕訳のインポート** をクリック
4. 「ファイルの準備」画面で、`output` フォルダの `freee用_仕訳データ_obc変換_001.csv` をドラッグ&ドロップ (または「ファイルを選択」で選ぶ)
5. 「読み込み項目の設定」で **税額の扱い** にチェック
   - 税抜経理 → 「全ての金額が外税」
   - 税込経理 → 「全ての金額が内税 + 税額自動計算あり」
6. 「設定する」をクリック
7. 「マッピング」画面で、勘定科目・補助科目・税区分を freee マスタへ対応付け
   - 自動マッチしたものはそのまま
   - 未マッチのものはプルダウンで該当する freee 項目を選択
   - 補助科目は「口座 / 取引先 / 品目」のいずれかを選ぶ
8. 「インポートを実行」をクリック
9. 完了後、「仕訳インポート履歴」で結果を確認

#### 2 つ目以降のファイル

`_001.csv` のインポートが完了したら、同じ手順で `_002.csv` をアップロードします。順番にアップロードしないと伝票が分断される場合があるので、必ず `_001` から順番に。

#### ロールバック (やり直したい場合)

「仕訳インポート履歴」→ 該当行の **削除** ボタンをクリック。⚠️ 取り込まれた振替伝票本体も同時に削除されるため注意。

**ログを保存する方法 (OS 共通):**

- **進捗ログのみ保存:** `> 進捗.log`
- **診断・監査ログのみ保存:** `2> 診断.log`

- **進捗と診断を別ファイルへ:** `> 進捗.log 2> 診断.log`

例 (Mac/Linux):
```
python3 obc_to_freee.py [引数] > 進捗.log 2> 診断.log
```

例 (Windows コマンドプロンプト):
```
python obc_to_freee.py [引数] > 進捗.log 2> 診断.log
```

## 7.5 入力ファイルの柔軟性

このスクリプトは奉行 CSV の形式が多少違っていても動くようになっています。

### 対応するエンコーディング (文字コード)

- **Shift-JIS (CP932)** — 奉行の標準出力
- **UTF-8** (BOM なし)
- **UTF-8 BOM 付き**
- **UTF-16** (LE / BE、BOM 必須)

`--encoding auto` (デフォルト) で自動判定します。明示指定したい場合は `--encoding cp932` のように指定可能。

### カラム順序の変更

奉行のバージョン違いや手動編集で列順が変わっていても動作します。スクリプトは **カラム名で値を取得**するため、列の並びは気にしません。

### 必須カラム (これが無いと変換できません)

| カラム名 | 用途 |
|---------|------|
| `日付` | freee の日付列 |
| `伝票No.` | freee の伝票番号 + 同一伝票のグルーピング |
| `借方勘定科目名` | freee の借方勘定科目 |
| `借方本体金額` | freee の借方金額 |
| `貸方勘定科目名` | freee の貸方勘定科目 |
| `貸方本体金額` | freee の貸方金額 |

これらのカラム名がヘッダー行に無い場合、スクリプトは **エラー停止**し、どのカラムが欠落しているかと、検出した実際のヘッダー一覧、ネクストアクションを表示します。

### オプショナルカラム (無くても処理継続)

取引先・部門・補助科目・税区分・税率・摘要・消費税額などは **無くても変換は完了**します。該当 freee 列が空欄になるだけです。実行時に「以下のオプショナルカラムは奉行 CSV に存在しないため freee 側で空欄になります」と警告が表示されます。

例えば「取引先関連 4 列が奉行側に無い」場合、freee 出力 CSV の取引先列は全行空欄になります。freee アップロード時に手動マッピングで対応可能です。

## 8. 困ったとき

### Q. `python: コマンドが見つかりません` と出る

Python がインストールされていない、または PATH が通っていません。[2. Python のインストール](#2-準備python-のインストール) のステップを最初からやり直してください。Windows の場合は「Add python.exe to PATH」のチェックを確認。

### Q. `FileNotFoundError: 奉行_勘定奉行仕分伝票データ上.csv` のようなエラー

奉行 CSV ファイルが作業フォルダにないか、ファイル名が一致していません。`dir` (Windows) または `ls` (Mac/Linux) でフォルダの中身を確認し、コマンドに書いたファイル名と一致させてください。

### Q. `UnicodeDecodeError` が出る

本スクリプトは CP932 / UTF-8 / UTF-8 BOM / UTF-16 を自動判定して読み込みますが、それ以外の特殊なエンコーディング (例: EUC-JP) は未対応です。`--encoding cp932` のように明示指定するか、奉行から CP932 (Shift-JIS) または UTF-8 で再エクスポートしてください。

### Q. 「想定外の税区分が見つかりました」とエラーレポートに表示された

奉行原本に変換マッピング未登録の税区分 + 税率の組み合わせが含まれています。スクリプトは変換を継続し、処理完了後のエラーレポートに検出パターン・件数・ネクストアクションを一覧表示します。奉行側で税区分を修正して再エクスポートするか、`obc_to_freee.py` ファイル冒頭の `TAX_MAP` 辞書に該当エントリを追加してから再実行してください (詳細は [9. 仕様の詳細](#9-仕様の詳細))。

### Q. freee アップロード時に「マスタで未登録の取引先があります」と表示

問題ありません。インポート画面でそのまま「新規登録」を選べば freee 側に取引先マスタが自動作成されます。事前にマスタ登録したい場合は freee の「取引先マスタ」画面で手動登録してください。

### Q. 文字化けする

出力 CSV を Excel で開くと文字化けする場合があります。スクリプトは **UTF-8 with BOM** で出力しているので Excel でも正しく開けますが、もし化ける場合は LibreOffice や Numbers で開いて確認してください。freee へのアップロードには影響しません。

### Q. 一度実行したらまた実行できる?

何度でも再実行可能です。同じ出力先フォルダに同名ファイルがあれば **上書き**されます。

## 9. 仕様の詳細

### 9-1. CLI 引数一覧

| 引数 | 必須 | 既定値 | 説明 |
|------|------|--------|------|
| `--input` | ✅ | — | 奉行 CSV ファイル (複数指定可、順に連結) |
| `--output-dir` | ✅ | — | 出力先ディレクトリ |
| `--output-prefix` | — | `freee用_仕訳データ_obc変換` | 出力ファイル名のプレフィックス |
| `--rows-per-file` | — | `10000` | 1 ファイルあたりの最大データ行数 |
| `--from` | — | なし | 開始日 `YYYY/MM/DD` |
| `--to` | — | なし | 終了日 `YYYY/MM/DD` |
| `--encoding` | — | `auto` | 奉行 CSV のエンコーディング (`auto` / `cp932` / `utf-8` / `utf-8-sig`)。auto で BOM 検出 + UTF-8 strict → CP932 フォールバック判定 |
| `--quiet-audit` | — | `False (抑制しない)` | 監査ログを抑制 (パイプ処理用) |
| `--output-partners` | — | `False (出力しない)` | 取引先マスタ CSV を追加出力する |
| `--partners-prefix` | — | `freee取引先マスタ` | 取引先マスタファイル名のプレフィックス |

### 9-2. 入力フォーマット (奉行エクスポート CSV)

奉行の「仕訳伝票データ」エクスポート CSV。エンコーディングは **CP932 / UTF-8 / UTF-8 BOM / UTF-16 を自動判定**。カラムはヘッダー名で参照するため**列順序を問わず**、必須カラム (日付・伝票No.・借方/貸方勘定科目名・借方/貸方本体金額) が揃っていればオプショナルカラム (取引先・部門・補助科目・税区分・税率・摘要・消費税額等) は欠落可。1 明細行は次のいずれか:

- 借方のみデータ
- 貸方のみデータ
- 両側にデータあり (例: 借 普通預金 322,113 / 貸 売上 337,700)

### 9-3. 出力フォーマット (freee 33 列拡張 / UTF-8 BOM)

```
[表題行], 日付, 伝票番号, 決算整理仕訳,
借方勘定科目, 借方科目コード, 借方補助科目, 借方取引先, 借方取引先コード,
借方部門, 借方品目, 借方メモタグ, 借方セグメント1〜3,
借方金額, 借方税区分, 借方税額,
貸方勘定科目, 貸方科目コード, 貸方補助科目, 貸方取引先, 貸方取引先コード,
貸方部門, 貸方品目, 貸方メモタグ, 貸方セグメント1〜3,
貸方金額, 貸方税区分, 貸方税額,
摘要
```

### 9-4. 行分解ルール

| 奉行行 | freee 出力 |
|--------|-----------|
| 借方のみ | 1 行: 借方 = 奉行借方 / 貸方 = 「複合」(同額・対象外) |
| 貸方のみ | 1 行: 借方 = 「複合」(同額・対象外) / 貸方 = 奉行貸方 |
| 両側あり | 2 行: 借方明細行 + 貸方明細行 (摘要は両行へ複製) |
| 両側空 | スキップ (奉行の空パディング行) |

### 9-5. 税区分マッピング

| 奉行略称 | + 税率 | → freee コード |
|----------|-------|----------------|
| 課仕入 | 10 | 課対仕入10% |
| 課仕入 | 8 | 課対仕入8%（軽） |
| 課売上 | 10 | 課税売上10% |
| 課売上 | 8 | 課税売上8%（軽） |
| 共仕入 | 10 | 共対仕入10% |
| 共仕入 | 8 | 共対仕入8%（軽） |
| 課仕免 | 10 | 課対仕入（控80）10% |
| 課仕免 | 8 | 課対仕入（控80）8%（軽） |
| 共仕免 | 10 | 共対仕入（控80）10% |
| 共仕免 | 8 | 共対仕入（控80）8%（軽） |
| 課売返 | 10 | 課税売返10% |
| 課売返 | 8 | 課税売返8%（軽） |
| 非売上 | — | 非課売上 |
| 非仕入 | — | 非課仕入 |
| 空 / 対象外 | — | 対象外 |

> 注: 税率 `0` または空欄の場合 (`課仕入`/`課売上`/`共仕入`/`課仕免`/`共仕免`/`課売返`/`非売上`/`非仕入`/`対象外` いずれも) は `対象外` として処理されます (エラー収集対象外)。`対象外` 略称・空略称も同様。freee コードの表記は公式サンプル CSV に準拠 (8% は全角カッコ `（軽）`、課売返は `課税売返` 略称)。

想定外の組み合わせは「対象外」で仮置きして変換継続し、処理完了後のエラーレポート (`[エラー N/M] 想定外の税区分が見つかりました` セクション) に検出パターン・件数・ネクストアクション付きで一覧表示します。アップロード前に必ず対処してください。

### 9-6. ノイズ除去

- 取引先名 = `その他取引先` または空白のみ → 空欄
- 取引先コード = `000000` または空白のみ → 空欄
- 部門名・補助科目 = `その他` → 空欄
- セル内 `\r`/`\n`/`\r\n` → 半角スペース 1 個
- 連続スペース → 1 個に縮約

### 9-7. 整合性チェック

出力後、伝票単位 (日付 + 伝票番号) の借方合計 vs 貸方合計を全件チェック。**未知の不一致が検出された場合は ERROR で非ゼロ終了**します。ただし出力 CSV 自体は書き出されています。終了コードが 1 の場合は **freee へアップロードせず**、スクリプト開発者へ該当伝票番号・日付を伝えてください。

### 9-8. ファイル分割

`--rows-per-file 10000` を指定した場合、1 ファイル目で 10,000 行に達した時点の伝票が終わるまで含めてから次のファイルへ。同一 (日付, 伝票番号) が複数ファイルに分かれることはありません。

### 9-9. freee 仕様の制約

- 1 ファイル最大 50,000 行 / 64 MB
- 必須列: `[表題行]`, 日付, 借方勘定科目, 借方税区分, 借方金額, 貸方勘定科目, 貸方税区分, 貸方金額
- 同一ファイル内で (日付, 伝票番号) の重複は許可されない (同じ伝票として扱う場合のみ複数行 OK)

### 9-10. 取引先マスタ CSV

#### CLI フラグ

| フラグ | 既定値 | 説明 |
|--------|--------|------|
| `--output-partners` | OFF | 指定すると取引先マスタ CSV を仕訳 CSV と同時に出力する |
| `--partners-prefix` | `freee取引先マスタ` | 取引先マスタファイル名のプレフィックス |

実行例:

```
python3 obc_to_freee.py \
  --input 上.csv 下.csv \
  --output-dir output \
  --output-prefix freee用_仕訳データ_obc変換 \
  --rows-per-file 10000 \
  --output-partners
```

出力ファイル: `output/freee取引先マスタ.csv`

#### 出力ファイル仕様

- **列数**: 57 列 (freee 公式「取引先インポート用テンプレート」と完全一致)
- **文字コード**: UTF-8 BOM 付き
- **行構成**: ヘッダー行 1 行 + 取引先データ行 N 行 (取引先コード昇順ソート)
- **充填列**: 1 列目「名前（通称）」、2 列目「取引先コード」、5 列目「正式名称（帳票出力時に使用される名称）」(= 名前（通称）と同値)。残り 54 列は空欄
- **ノイズ除去**: 取引先コード `000000` / 空白、取引先名「その他取引先」/ 空白 は除外
- **同コード異名**: 借方・貸方で表記揺れがある場合は出現回数最多の名前を採用し、stderr に警告を出力

#### freee 側の取り込み手順

取引先マスタは仕訳 CSV より **先に** 取り込む必要があります。

1. freee 会計にログイン
2. **マスタ・口座 → 取引先** を開く
3. 画面右上の **インポート** ボタンをクリック
4. `freee取引先マスタ.csv` をドラッグ&ドロップ (または「ファイルを選択」)
5. 「**取引先コードを元にインポート**」を選択
6. 「インポートを実行」をクリック
7. 完了後、**仕訳 CSV のインポートを実行する** (→ [6. freee へアップロードする手順](#6-freee-へアップロードする手順))

> 取引先マスタを先に取り込むことで、仕訳インポート時の「マスタで未登録の取引先があります」確認画面が大幅に減ります (全取引先が事前登録済みになるため)。
