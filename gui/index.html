    freee へのアップロード手順

    1
    取引先マスタを先に取り込み
    1. freee にログイン → マスタ・口座
    2. 取引先 → CSV インポート
    3. 「取引先コードを元にインポート」を選択
    4. 取引先マスタ CSV をアップロード
    1
    仕訳 CSV を取り込み
    1. freee にログイン → 取引入力
    2. 振替伝票 → インポート
    3. 「他社会計ソフト仕訳のインポート」を選択
    4. 仕訳 CSV をアップロード (ファイルが複数ある場合は順番に)
    2
    過去マッピング削除の注意

    重複インポートを行った場合、以前のインポートで作成された科目マッピング設定が残っていると正しく取り込まれない場合があります。

    freee サポート 「重複インポート時の科目設定削除手順」 を参照してください。
